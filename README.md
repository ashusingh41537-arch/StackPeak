# 🚀 Job Portal Project

A Full Stack Job Portal Application built using React and Spring Boot.

---

## 🔧 Tech Stack

- Frontend: React.js, Redux, Tailwind CSS
- Backend: Spring Boot (Java)
- Database: MySQL
- Authentication: JWT (JSON Web Token)

---

## ✨ Features

### 👨‍💻 User Side
- User Registration & Login
- Browse Jobs
- Apply for Jobs
- View Applied Jobs
- Update Profile

### 🛠️ Admin Side
- Manage Companies (Add / Update / Delete)
- Manage Jobs (Create / Update / Delete)
- Manage Users
- View Applicants and Update Status

---

## 📊 Admin Dashboard
- Total Companies
- Total Jobs
- Total Users
- Total Applications
- Recent Jobs Overview

---

## 🔐 Security
- JWT-based Authentication
- Protected Routes (Frontend + Backend)

---
